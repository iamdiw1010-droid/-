# 🪷 เว็บแอป "ลอยกระทงออนไลน์สำหรับคู่รัก" (Romantic Loy Krathong)

เว็บแอปพลิเคชันสำหรับสร้างความประทับใจและเซอร์ไพรส์แฟนในค่ำคืนวันลอยกระทง ออกแบบมาโดยเฉพาะสำหรับการเปิดบนสมาร์ตโฟน (iPhone Safari & Android Chrome) ด้วยความรู้สึกที่อบอุ่น โรแมนติก ลื่นไหล 60fps

---

## ✨ จุดเด่นของโปรเจกต์
- **Passcode Gate (ด่านรหัสผ่านวันสำคัญ)**: ล็อกด้วยวันครบรอบ (DD/MM/YY) โฟกัสข้ามช่องอัตโนมัติ ตรวจสอบคำตอบแบบยืดหยุ่น (พ.ศ. 2568, 68 หรือ ค.ศ. 2025, 25) มีเอฟเฟกต์การ์ดสั่นเมื่อตอบผิดและแสดงคำใบ้
- **Mobile-First Glassmorphism UI**: โทนสีกรมท่าค่ำคืน ผสานแสงเทียนสีทอง และสีชมพูโรแมนติก รองรับ Safe Area ของ iPhone และ dynamic viewport height (`100dvh`)
- **Pure Canvas API Background**: ฉากท้องฟ้าไล่เฉด, ดวงดาวกะพริบด้วย sin wave, พระจันทร์เต็มดวงพร้อมรัศมีแสงนวลและรอยหลุม, โคมลอยแกว่งไกวตามสายลม, และผิวน้ำพร้อมระลอกคลื่นแสงสะท้อนดวงจันทร์และโคม
- **กระทงเวกเตอร์ 3 สไตล์ (SVG)**:
  1. *กระทงใบตอง* (คลาสสิก อบอุ่น พร้อมดอกดาวเรือง)
  2. *กระทงดอกบัว* (หวานละมุน กลีบบัวซ้อนชมพู-ขาว)
  3. *กระทงพาสเทล* (มินิมอล โรแมนติก ประดับมุก)
  - พร้อมเปลวเทียนกะพริบสมจริงและแสงเรืองสีทอง
- **State Machine & Framer Motion Transitions**:
  - `gate` ➔ `landing` ➔ `craft` ➔ `releasing` ➔ `surprise`
- **ซองจดหมายเซอร์ไพรส์ & Typewriter Effect**: ซองจดหมายเปิดฝา 3D พร้อมกระดาษจดหมายเลื่อนขึ้นมาและพิมพ์ข้อความทีละตัวอักษร
- **Smart Asset Handling**:
  - ระบบเพลงเปิดตาม Autoplay Policy เมื่อผู้ใช้แตะปุ่มเริ่มต้น พร้อม Fade-in นุ่มนวล 1.5 วินาที
  - หากไม่มีไฟล์เพลง (`public/music.mp3`) หรือรูปภาพ (`public/photo1.jpg`) ระบบจะทำงานต่อได้อย่างราบรื่นและซ่อนปุ่มที่เกี่ยวข้องโดยไม่มี error

## 🛠️ วิธีการติดตั้งและรันในเครื่อง (Local Development)

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รัน Dev Server
```bash
npm run dev
```
เปิดบราวเซอร์ที่ `http://localhost:5173/` (แนะนำให้กด `F12` แล้วเลือก Device Mode เป็น iPhone / 375x667 เพื่อสัมผัสประสบการณ์ที่ดีที่สุด)

### 3. ตรวจสอบการ Build สำหรับ Production
```bash
npm run build
```

## 💌 วิธีปรับแต่งข้อความและไฟล์เพลง/รูปภาพ

### 1. แก้ไขข้อความใน `src/config.js`
เปิดไฟล์ `src/config.js` แล้วปรับเปลี่ยนข้อความตามที่ต้องการ:
```javascript
export const CONFIG = {
  // ด่านรหัสผ่านวันครบรอบ (Passcode Gate)
  gateEnabled: true,                             // true: เปิดด่านรหัสผ่าน, false: ข้ามไปหน้า Landing ทันที
  gateQuestion: "วันครบรอบของเราคือวันไหนนะ?",     // คำถามที่แสดงบนการ์ด
  gateHint: "คำใบ้: วันแรกที่เราเริ่มต้นด้วยกัน ✨", // คำใบ้เมื่อตอบผิดครบจำนวนครั้ง
  gateAnswerDay: 25,                             // วันที่คำตอบ (1-31)
  gateAnswerMonth: 3,                            // เดือนคำตอบ (1-12)
  gateAnswerYearBE: 2568,                        // ปี พ.ศ. (ระบบรองรับ 2568, 68, 2025, 25 อัตโนมัติ)
  gateSuccessText: "ถูกต้องที่สุดเลยค่ะ/ครับ 💛",
  gateMaxAttemptsBeforeHint: 2,                  // จำนวนครั้งที่ตอบผิดก่อนแสดงคำใบ้

  // ข้อความต้อนรับบนหน้าแรก
  greeting: "สุขสันต์วันลอยกระทง ✨\nเป็นวันที่เราไปเดทกันครั้งแรกที่สวนรถไฟที่กรุงเทพ",

  // ข้อความบนปุ่มเริ่มต้น
  startButton: "แตะเพื่อเริ่มลอยกระทง",

  // ชื่อคู่รัก (กำหนดเป็น ดิว & จินนี่ โดยไม่ต้องกรอกเอง)
  defaultCoupleName: "ดิว & จินนี่",

  // ข้อความในจดหมายเซอร์ไพรส์ (ใช้ \n เพื่อขึ้นบรรทัดใหม่)
  surpriseMessage: "ขอบคุณที่เป็นความสุขของเค้าในทุกๆวันนะ\nขอให้ทุกคำอวยพรสมปราถนา\nไว้จะพาไปเที่ยวบ่อยๆอีก รักนะ ❤️",

  // รายการรูปภาพสำหรับ Photo Slideshow
  photos: [
    { src: "/photos/1.jpg", caption: "วันที่เราได้ไปเดทแรกที่สวนรถไฟด้วยกัน 🚂✨" },
    { src: "/photos/2.jpg", caption: "รอยยิ้มที่สดใสที่สุดของจินนี่ 💖" },
    { src: "/photos/3.jpg", caption: "จับมือเดินไปด้วยกันทุกที่นะ 🌸" },
    { src: "/photos/4.jpg", caption: "ความสุขง่ายๆ ในทุกๆ วันที่มีเธอ ☀️" },
    { src: "/photos/5.jpg", caption: "รักจินนี่ที่สุดในโลกเลยนะ 💛" },
  ],
  slideshowIntervalMs: 4500,
  slideshowTitle: "ภาพความทรงจำของเรา",

  // เส้นทางไฟล์เพลงใน public/
  musicSrc: "/music.mp3",
  musicVolume: 0.4,

  // ระยะเวลาดีเลย์ (ms) ก่อนแสดงโคมเซอร์ไพรส์
  surpriseDelayMs: 3000,
}
```

### 2. การใส่และแปลงรูปภาพอัตโนมัติ (Photo Optimizer)
- วางรูปดิบในโฟลเดอร์ `photos-raw/` (รองรับ `.jpg`, `.jpeg`, `.png`, `.webp`, `.heic`)
- รันคำสั่งแปลงและบีบอัดรูปภาพอัตโนมัติ:
```bash
npm run photos
```
สคริปต์จะหมุนภาพตาม EXIF, ย่อขนาดให้ด้านยาวสุดไม่เกิน 1280px, บีบอัดเป็น WebP คุณภาพสูง ลบข้อมูล GPS และสร้างไฟล์ `manifest.json` ให้พร้อมใช้งานในโฟลเดอร์ `public/photos/` ทันที

### 3. การใส่ไฟล์เพลง
นำไฟล์เพลงของคุณมาวางในโฟลเดอร์ `public/`:
- **เพลงบรรเลง**: ตั้งชื่อว่า `music.mp3` วางที่ `public/music.mp3`
*(หากยังไม่มีไฟล์ ระบบจะเล่นต่อไปได้ตามปกติโดยซ่อนปุ่มเสียง)*

## 🚀 การ Deploy สู่ Vercel / Netlify

โปรเจกต์นี้เป็น Client-side SPA มาตรฐาน สามารถ Deploy ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่มเติม:

### Deploy ผ่าน Vercel CLI:
```bash
npx vercel
```
หรือเชื่อมต่อ GitHub Repository กับ **Vercel Dashboard**:
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
